# ☕ Java Quiz — Records

## 📌 Question (EN)

Identify correct statement(s) about Java records.  
You have to select **3 options**.

### Options

1. Records are implicitly final.
2. All nested record classes are implicitly static.
3. Records are meant to restrict the number of instances of that type.
4. Records are implicitly sealed.
5. Record instances are immutable.

2. Todas as classes record aninhadas são implicitamente static.
3. Records foram criados para restringir o número de instâncias desse tipo.

5. As instâncias de um record são imutáveis.
